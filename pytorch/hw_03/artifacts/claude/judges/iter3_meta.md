# Итерация 3, мета-взгляд на границы (opus_iter3_v1 и opus_iter3_v2, одни и те же 200)

Источники: Opus 5.5, один повтор на промпт; метки из звёзд; признаки — мои регулярки. «TF-IDF против» — ответ TF-IDF + LR вне фолда на train (5 фолдов, macro-F1 0,73) не совпал с правилом.

## Диагноз

**1. v2 хуже v1 — вероятно, но не доказано.** Разница +0,036 (бутстреп, 95%: −0,006…0,081). Расхождения 13 против 6, точный тест знаков p=0,17. Повтора v1 на тех же 200 нет: сколько расхождений даёт случайность модели, неизвестно.

**2. Граница не сдвинулась, а сменила признаки.** Ответы v1 66/66/68, v2 67/64/69.

| переход v1→v2 | n | v2 прав |
|---|---|---|
| neutral→negative | 7 | 2 |
| negative→neutral | 7 | 3 |
| neutral→positive | 3 | 0 |
| positive→neutral | 1 | 1 |
| positive→negative | 1 | 0 |

Между negative и neutral потоки равны: порог тот же, но v2 решает по другим словам; из 14 перестановок верны 5. К positive ушли 3 neutral, все ошибочно. F1: neutral 0,71→0,66, negative 0,80→0,76, positive 0,90→0,88.

**3. Расхождения по правкам v2** (привязка моя, по тексту):

| правка v2 | v2 прав | v1 прав |
|---|---|---|
| долгая доставка не negative | 3 | 1 |
| «качество хорошее» = похвала в целом | 0 | 3 |
| «вернувшиеся деньги не отменяют» | 0 | 3 |
| нажим: «!!», «как на ребёнка», «не соответствует» | 2 | 2 |
| «одиночный ! не меняет», «почти ничья» | 0 | 3 |

| прочее | 1 | 0 |

**4. Почему верные «в среднем» правила вредят.** Правило меняет ответ только там, где модель решила бы иначе, и проверять его надо на этих отзывах, а не на всех с признаком.

| признак, train | правило | доля, все | доля, где TF-IDF против |
|---|---|---|---|
| «качество хорошее» + размер | positive | 0,52 (n=123) | 0,27 (n=59) |
| частичный возврат | negative | 0,55 (n=96) | 0,37 (n=35) |
| «!!» в спокойной претензии | negative | 0,57 (n=105) | 0,47 (n=55) |
| приговор (v1) | negative | 0,77 (n=1244) | 0,45 (n=253) |
| «спасибо» + претензия (v1) | positive | 0,81 (n=213) | 0,29 (n=34) |
| долгая доставка, пришло, без спора | не negative | 0,85 (n=1068) | 0,53 (n=144) |
| «N звёзд за …» | класс по N | 0,90 (n=42) | 0,82 (n=17) |

У Opus на итерации 3 то же. Где v1 не пошла за признаком v2, она права: «качество хорошее» 3 из 3, возврат или спор 7 из 7, «!!» 5 из 6.

Правила v1 по этой проверке тоже ниже 0,5, но v1 ставит их ожиданием и велит «решать по общему тону автора». v2 заменила это закрытым списком отступлений и запретила другие признаки («одиночный «!» и «очень» тоже»). Вредит не содержание правил, а то, что решение перешло от модели к правилу.

**5. Предел слов.** Слова помогли в v0→v1: сообщили факт о данных, которого модель не знала (звёзды ставят за то, что подвело). Остаток — шум звёзд (итерация 2: в 25 из 38 ошибок истина — меньшинство своего типа). Правило тянет к большинству типа, а модель отходит от него, когда видит причину. Словами — устройство данных, границу проводит модель.

**6. Мои ошибки итерации 2.** П2 я проверял, сложив все N: 0,45/0,30/0,24 (n=33). По отдельным N метка совпадает с названной в 0,90 (n=42): «три звезды за доставку» — оценка всего отзыва, пример v1 «две звезды за доставку» верен. П3 и есть замена «общего тона» списком сигналов.

## Правки промпта: v3 = v1 + одна правка

**П1.** В пункте «Подвела сама покупка» удалить «шёл месяцами,». В конец пункта «Вещь дошла, но не устроила свойствами» добавить:
> Долгая доставка, если вещь в итоге пришла, сама по себе negative не делает.

Попарно: 3 верных против 1 ошибки. Train: пришло, без спора и резкости 0,15/0,33/0,52 (n=1068), 2 месяца и больше 0,32/0,45/0,23 (n=164). Там, где TF-IDF говорит negative, не negative 0,53 (n=144) — на грани. Эффект — 2–4 отзыва из 200 (вывод).

Остальные правки v2 не прошли ни п. 4, ни попарное сравнение. Sonnet, у которой своя граница грубее, правила могут и помочь (не проверено).

## План итерации 4

Opus v1 и v3 попарно мало что решат: правка трогает 2–4 отзыва, это шум.

| вариант | что даёт | цена |
|---|---|---|
| А. Opus v1 и v3 | «правка не вредит Opus», слабо | 2 прогона, ~1 $ |
| Б. Sonnet v1 и v3 + Opus v3 | выбор для целевой модели; Opus v3 — для траектории и опор | 3 прогона |

В обоих — повтор Opus v1 на выборке итерации 3 (~0,4 $, новых данных не тратит). Гипотеза: 13 против 6 — эффект промпта; если v1 расходится сама с собой в 15+ отзывах, п. 1 снимается.

Правило решения заранее: v3, если «только v3 верно» ≥ «только v1 верно» на Sonnet, иначе v1.

## Чего не делать

- Не убирать «решай по общему тону автора» и не заменять её списком сигналов.
- Не давать примеры-триггеры («качество хорошее», «!!»): модель читает пример как правило.
- Не сообщать вероятности («почти ничья, neutral чаще»): модель берёт большее.
- Не заменять правила таблицей долей по типам: та же тяга к большинству (не проверено).
- Не принимать новое правило, у которого доля там, где TF-IDF против, ниже 0,5.
