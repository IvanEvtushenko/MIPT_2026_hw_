# Итерация 1, линза «шум разметки» (прогон opus_iter1_v0, промпт v0)

Источники: группы — мой ручной разбор 60 текстов (вывел); распределения меток — грубые регулярки по train, n=12 000 (проверил).

Граница negative–neutral — 40 ошибок из 60. Главный шум: метка neutral у резких текстов («Выброшенные деньги», «фуфло»). На train у текстов с резкими словами без похвалы n=1428: neg 0,77 / neu 0,22 / pos 0,01. Модель уже идёт за ним: 32 из 35 таких отзывов прогона — negative. Обратный шум: positive у отзывов из одних жалоб, negative при «ставлю 5*» (ru-24698).

Звёзды, названные в тексте, на train: «3 звезды» n=73 → neu 0,97; «4» n=18 → pos 0,78; «2» n=44 → neg 0,66; «1» n=28 → neg 0,71. То есть 1–2 → negative, 3 → neutral, 4–5 → positive.

Систематическая ошибка модели — спокойная жалоба на ткань, швы, цвет. На train (до 20 слов, без резких слов, похвалы, возврата и спора) n=882: neu 0,58 / neg 0,33 / pos 0,09. В прогоне таких 16: верных сейчас 8, при ответе neutral было бы 12. Похоже, её тянет фраза промпта «вещь нельзя носить → negative», а на train спокойное «носить не буду / не одену» n=67: neu 0,69 / neg 0,28.

Потолок. Сейчас 0,706 (бутстрэп, 95% интервал 0,64–0,76, n=200). Если исправить все (в) — 0,73. Плюс (б) с приором — 0,77, это верхняя оценка: приоры собьют часть верных. Остальные 46 ошибок из 60 (0,77) промптом не лечатся. Для сравнения: ruBERT на всём train — 0,736 на test (n=8578, artifacts/metrics_summary.csv). Реалистичная цель — 0,73–0,75, на 200 отзывах это неотличимо от шума.

## Правки промпта

1. Заменить «Низкая оценка — negative, средняя — neutral, высокая — positive» на «1–2 звезды — negative, 3 — neutral, 4–5 — positive». Проверка — звёзды выше. Эффект: «4 звезды с замечанием» — positive, «2 звезды» — negative; сила не оценена.
2. Из описания negative убрать «вещь нельзя носить». В neutral добавить: «Спокойная жалоба на ткань, швы, нитки, цвет, запах — даже из нескольких пунктов и даже с „носить не буду“, „жаль“, „ожидала лучшего“, „(((“ — это neutral, если нет резких слов (ужас, фуфло, ерунда, деньги на ветер, выкинуть), „не рекомендую“, возврата, спора или непришедшего товара». Проверка: n=882 neu 0,58; «носить не буду» n=67 neu 0,69; короткая жалоба на материал до 8 слов n=229 neu 0,66. Эффект в прогоне: +4 верных (8 → 12 из 16).
3. В negative явно перечислить: «резкие слова, „деньги на ветер“, „не рекомендую“, „не советую“, товар не пришёл и деньги не вернули — negative, даже если претензия одна». Проверка: резкие слова n=1428 neg 0,77; «не рекомендую/не советую» n=463 neg 0,82; не пришёл без возврата n=868 neg 0,88. Эффект: страховка от перекоса после правки 2.
4. В positive добавить: «Размер не подошёл, но покупатель винит свой выбор или советует брать другой размер и при этом хвалит вещь — positive». Проверка: n=89 pos 0,63 / neu 0,31; без похвалы n=55 neu 0,65 — похвала обязательна. В прогоне 3 срабатывания, сейчас 0 верных, по правилу будет 2.
5. Слабая, можно пропустить: «Жалоба только на долгую доставку, с нажимом („очень долго“, „!!!“) — negative». Проверка: n=104 neg 0,59 / neu 0,38. В прогоне 2 таких отзыва, сейчас 0 верных.

## Чего не делать

- Правило «похвала + жалоба → positive»: train n=2269 pos 0,55, в прогоне было бы 21 верный из 43 вместо 32.
- Не лечить neutral у резких текстов (10 ошибок) и negative у спокойных жалоб на размер (5): модель идёт за приором train, это шум.
- «Брак» как признак neutral: на train без резких слов n=92 neg 0,58.
- Выводы по разнице меньше 0,05 между итерациями на 200 отзывах.
