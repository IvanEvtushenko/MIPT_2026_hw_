# Итерация 1, линза «границы классов» (v0, opus_iter1_v0)

Признаки выделены регулярками, это приближение. Train: метки из звёзд, n=12 000, классы поровну. Доли — negative/neutral/positive.

## Диагноз

Ошибки прогона (Opus 5.5, один повтор):

| истина → ответ | n | состав |
|---|---|---|
| neutral → negative | 25 | 13 резкие слова / «не советую»; 6 спокойная жалоба; 3 грусть; 3 возврат |
| negative → neutral | 15 | 4 спокойная жалоба; 5 жалоба с похвалой; 4 размер, цвет |
| positive → neutral | 16 | 8 жалоба с похвалой или «спасибо»; 4 спокойная жалоба |

«Что случилось» вместо «насколько недоволен» — частично да: модель ставит negative за брак, не тот размер, длинный список дефектов. Звёзды идут за событием только при невручении и возврате.

| признак (train) | n | доли |
|---|---|---|
| не пришло, без эмоций | 961 | 0,74 / 0,21 / 0,05 |
| возврат или спор, без эмоций | 994 | 0,65 / 0,28 / 0,07 |
| брак, не тот товар/размер, без возврата и эмоций | 406 | 0,37 / 0,49 / 0,15 |
| спокойная жалоба без похвалы | 1660 | 0,27 / 0,59 / 0,14 |
| то же: 1 / 2 / 3+ дефекта, доля neutral | 1068 / 285 / 55 | 0,62 / 0,60 / 0,60 |
| жалоба + резкие слова, «не советую», «деньги на ветер» | 879 | 0,62 / 0,34 / 0,05 |
| только грусть («разочарована», «жаль») или «носить не буду» | 414 | 0,36 / 0,53 / 0,11 |
| спокойная жалоба + похвала вещи или «спасибо» | 938 | 0,05 / 0,26 / 0,70 |
| жалоба + только «быстрая доставка» | 306 | 0,13 / 0,42 / 0,45 |
| «спасибо» + жалоба на размер/качество | 182 | 0,10 / 0,20 / 0,70 |
| «спасибо» + невручение/возврат | 129 | 0,59 / 0,22 / 0,19 |
| «за свои деньги / за такую цену» + «норм» | 131 | 0,08 / 0,38 / 0,53 |

Число дефектов на звёзды не влияет, влияет тон. Похвала вещи при жалобе тянет к positive.

## Правки промпта

**П1. Заменить** в negative «пришёл не тот товар или брак» на:
> negative — товар не пришёл, деньги возвращали через спор, автор резко ругает вещь («ужас», «фуфло», «тряпка»), отговаривает («не советую»), считает деньги выброшенными. Брак, не тот размер или цвет без возврата и без резких слов — чаще neutral.

Train 0,49 neutral (n=406). Прогон: 1 → 3 верных из 3.

**П2. Добавить** в «Спорные случаи»:
> Силу недовольства задают слова автора, а не число недостатков. Спокойный перечень даже из трёх-четырёх дефектов — neutral.

Train 0,59 neutral (n=1660). Прогон: 11 → 14 из 27.

**П3. Добавить:**
> Грусть без резких слов («разочарована», «жаль», «ожидала лучшего», «носить не буду») и восклицательные знаки сами по себе не делают отзыв negative.

Train 0,53 neutral (n=414); «ожидала лучшего» 0,80 (n=65). Прогон: 9 → 9, вес ниже.

**П4. Заменить** строку про neutral/positive на:
> Если кроме недостатка есть конкретная похвала вещи (качество, ткань, пошив, цвет, «красивая», «нравится») или «спасибо», а резких слов нет — positive, даже если недостаток описан подробнее. Neutral — когда вещь не похвалили совсем. Одна похвала быстрой доставки не решает.

Train 0,70 positive (n=938). Прогон: 10 → 15 из 18.

**П5. Заменить** строку про «спасибо» на:
> «Спасибо» при жалобе на размер или качество — скорее positive; при невручении или возврате — negative.

Train 0,70 positive (n=182) против 0,59 negative (n=129).

**П6. Удалить** «за свои деньги нормально» из примеров neutral: 0,53 positive (n=131). «Так себе» оставить: 0,76 neutral (n=86).

Итого по прогону при полном следовании: около +8–10 верных из 200, в основном П2 и П4.

## Чего не делать

- Не смягчать резкие слова и «не советую»: это 13 из 25 ошибок neutral → negative, но train 0,62 negative (n=879), это шум звёзд.
- Не трогать невручение и возврат: 0,74 и 0,65 negative даже без эмоций.
- Не двигать спокойные жалобы на размер в negative: «не подошёл / мал / велик» — 0,28/0,63/0,09 (n=428).
- Не вводить правила по длине отзыва и по быстрой доставке: разница 0,05–0,1.
