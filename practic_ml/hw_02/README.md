# ДЗ 2. Обучение без учителя, вариант C

Решение: [02_Решение_C.ipynb](02_Решение_C.ipynb), все выводы, таблицы и графики в нём сохранены. Условие в шаблоне [02_Задание.ipynb](02_Задание.ipynb), данные в `02_Данные.zip`; оба файла выданы и не менялись.

Вариант C: 5000 окон датчиков смартфона (UCI HAR), 12 признаков, поиск режимов движения.

## Запуск

Нужны Python 3.12, NumPy, pandas, matplotlib, scikit-learn и SciPy; точные версии печатает последняя кодовая ячейка. Достаточно CPU, полный запуск занимает около 5 с. Откройте ноутбук из этого каталога и выполните Restart and Run All: архив с данными читается по относительному пути.

## Отличия от шаблона

- В ячейке загрузки `VARIANT = "C"`, файлы ищутся по окончанию пути: в архиве они лежат внутри папки `02_Данные/`.
- Перед заданием 1 добавлена ячейка с гипотезами, записанными до расчётов.
- В задании 7 проверка по `audit_label` вынесена в отдельную ячейку после фиксации выбора.
